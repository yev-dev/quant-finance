# Requirements Management

This project uses `pip-tools` to manage dependencies and generate platform-specific requirements files.

## Files

- `requirements.in` - Input file with high-level dependencies
- `requirements.txt` - General requirements (generated by pip-compile)
- `requirements-windows.txt` - Windows-specific requirements
- `requirements-linux.txt` - Linux-specific requirements

## Platform-Specific Installation

### Windows
```bash
pip install -r requirements-windows.txt
```

**Prerequisites for Windows:**
- Microsoft Visual C++ 14.0 or greater (Visual Studio Build Tools)
- For better performance with numerical libraries, consider Intel MKL

### Linux (Ubuntu/Debian)
```bash
# Install system dependencies first
sudo apt-get update
sudo apt-get install python3-dev build-essential libopenblas-dev liblapack-dev libxml2-dev libxslt1-dev

# Install Python packages
pip install -r requirements-linux.txt
```

### Linux (CentOS/RHEL/Fedora)
```bash
# Install system dependencies first
sudo yum install python3-devel gcc blas-devel lapack-devel libxml2-devel libxslt-devel

# Install Python packages
pip install -r requirements-linux.txt
```

## Updating Dependencies

To update the requirements files:

1. Edit `requirements.in` to add/remove/update package versions
2. Regenerate the requirements files:

```bash
# Install pip-tools if not already installed
pip install pip-tools

# Generate general requirements
pip-compile --output-file requirements.txt requirements.in

# For platform-specific files, manually update them based on the general requirements
# and add platform-specific notes/modifications as needed
```

## Key Platform Differences

### Windows-specific considerations:
- Requires Visual C++ Build Tools for packages with native extensions
- Some packages may have different wheel distributions
- PowerShell or Command Prompt for installation

### Linux-specific considerations:
- Requires development headers (python3-dev, build-essential)
- System-level BLAS/LAPACK libraries recommended for performance
- Unix-specific packages (pexpect, ptyprocess) included
- Package manager integration for system dependencies

### macOS-specific (current development platform):
- Includes appnope for IPython/Jupyter integration
- May require Xcode Command Line Tools
- Homebrew can provide system-level dependencies

## Performance Optimizations

### For numerical computing workloads:
- **Intel MKL**: Provides optimized BLAS/LAPACK routines
- **OpenBLAS**: Open-source alternative to MKL
- **System BLAS**: Use system-provided BLAS libraries when available

### Installation with optimized libraries:
```bash
# Using conda for MKL-optimized packages
conda install numpy scipy scikit-learn matplotlib pandas

# Or specify MKL explicitly
pip install numpy[mkl] scipy[mkl]
```

## Docker Support

For consistent cross-platform deployment, consider using Docker:

```dockerfile
# Example Dockerfile
FROM python:3.11-slim

# Install system dependencies (Linux)
RUN apt-get update && apt-get install -y \
    build-essential \
    libopenblas-dev \
    liblapack-dev \
    && rm -rf /var/lib/apt/lists/*

# Install Python dependencies
COPY requirements-linux.txt .
RUN pip install -r requirements-linux.txt

# Copy application code
COPY . /app
WORKDIR /app
```

## CI/CD Considerations

For continuous integration across platforms:

```yaml
# Example GitHub Actions matrix
strategy:
  matrix:
    os: [ubuntu-latest, windows-latest, macos-latest]
    python-version: [3.9, 3.10, 3.11]

steps:
  - name: Install dependencies (Ubuntu)
    if: matrix.os == 'ubuntu-latest'
    run: |
      sudo apt-get update
      sudo apt-get install -y build-essential libopenblas-dev
      pip install -r requirements-linux.txt
  
  - name: Install dependencies (Windows)
    if: matrix.os == 'windows-latest'
    run: pip install -r requirements-windows.txt
```
